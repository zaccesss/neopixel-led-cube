All notable changes to this project are recorded here.

## [1.0.2] - 2026-08-12

### Added

- Community health files, markdown lint configuration and issue and pull request templates
- CITATION.cff and a Citing This Work section
- Registered the repository with Zenodo for a permanent, citable DOI

### Changed

- Tech Stack section now uses an animated icon table instead of plain badges
- Contact and Support section presented as a callout
- Repository dual-licensed: written and visual content under CC BY-NC-ND 4.0, the Arduino sketch under MIT

## [1.0.1] - 2026-05-02

### Fixed

- Documentation and gallery corrections following the initial release

## [1.0.0] - 2026-05-02

### Added

- Initial release: 4x4x4 NeoPixel LED cube firmware for Arduino Uno with four animation modes, LDR-driven auto brightness and button controls
- Hardware build guide, software architecture documentation and FAQ
